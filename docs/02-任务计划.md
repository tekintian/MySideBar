## 2. 任务细则

### T0 原型验证（前置，必须先做）

目的：消除 T17 与 T3 的两个不确定点。

1. 在 ST4 中验证：将菜单文件写入 `Packages/User/MySideBar/` 是否能覆盖包内同名菜单，并确认生效时机（即时 / 需重启）。
2. 在 macOS 上验证：`ctypes.util.find_library('Foundation')` 是否成功返回；失败时的兜底路径是否可用。
3. 在 Windows 上验证：`os.rename` 对目录整树搬移的行为、大小写重命名的中间名方案。
4. 在已装 ChineseLocalization 的环境中验证：原生侧边栏菜单被翻译后，本插件空壳命令遮蔽是否仍然生效。

**通过标准**：四点均有明确结论，并写回 `01-技术方案.md` 的 V1、V2、V6。

---

### T1 项目骨架与设置

- 创建 `mysidebar/__init__.py`、`MySideBar.sublime-settings`、`messages/install.txt`。
- `plugin_loaded()` 只做三件事：加载设置、首次语言询问（若 `first_run`）、应用菜单。
- 设置项按方案第 8 节完整定义。

**通过标准**：ST4 中插件加载无异常，日志无报错。

---

### T2 i18n 与语言策略

- `i18n.t(key, **kwargs)`。
- 语言读写：仅从设置项读取 `ui_language`，**不含任何区域探测代码**。
- 首次安装若 `first_run == true`，弹出一次性语言选择（`English` / `简体中文` / `繁體中文`）；选择或取消后写入设置并置 `first_run = false`。
- 无窗口时跳过询问，保留 `first_run = true`。
- 提供开发期检查：源码中不允许出现硬编码用户可见字符串。

**通过标准**：首次安装弹出一次选择后不再弹出；切换 `ui_language` 后运行期提示语正确切换。

---

### T3 platform 与 trash

- `platform.py`：`open_terminal(path)`、`open_with_default(path)`、`reveal(path)`、`escape_win(path)`。
- `trash.py`：三平台 `send2trash`，惰性加载，失败返回 `False`（由调用方决定是否永久删除）。
- Windows 一律列表传参，禁止 `shell=True`。

**通过标准**：三平台各执行一次打开终端、打开文件、送回收站。

---

### T4 api.py 重写

- `SideBarSelection`、`SideBarProject`、`SideBarItem`。
- 不使用全局缓存与哨兵命令。
- 父项判断用 `commonpath`。
- `retarget_views` 用 `normcase`。
- 禁止裸 `except: pass`。

**通过标准**：
- 多选混合文件与目录时，`without_child_items` 结果正确。
- 目录改名后，其下已打开视图全部 retarget 到新路径。

---

### T5 基础文件操作命令

- 新建文件 / 新建文件夹（含父目录创建）。
- 复制副本 / 移动（含目标冲突确认）。
- 删除（回收站 → 失败兜底永久删除确认）。
- 重命名（单文件，走原生行为语义但由插件实现，保证视图联动）。

**通过标准**：每种操作在文件、目录、多选三种场景下结果正确。

---

### T6 打开与终端命令

- 编辑 / 在右侧编辑 / 用系统程序打开 / 在当前终端打开 / 在新窗口打开 / 定位。
- 三平台分支。

**通过标准**：三平台各验证一次。

---

### T7 剪贴板命令

- 侧边栏私有剪贴板（`cut` / `copy` / `paste`）。
- 与系统剪贴板双写（用户从系统文件管理器复制路径后可在侧边栏粘贴）。
- 粘贴冲突确认（不使用原插件的 `show_input_panel("BUG! xD")` 占位做法）。
- 复制名称 / 复制相对路径 / 复制绝对路径。

**通过标准**：剪切后粘贴到另一目录，原位置消失；跨进程复制粘贴可用。

---

### T8 文件名递归搜索

- 重写原 Instant File Search：独立命令 + InputPanel（或搜索视图）。
- 防抖、结果上限、默认排除目录（来自设置 `exclude_dirs_for_search`）。
- 匹配范围可选：文件名 / 全路径。
- 结果为新 scratch 视图，条目可点击。

**通过标准**：在含 `node_modules` 的工程中搜索，速度与结果正确。

---

### T9 编码转换

- 打开 GBK / 保存 GBK / 转换为 UTF-8 / 转换为 GBK。
- 不使用 `.dump`。
- 大文件保护、非法字节报错。

**通过标准**：GBK 文件打开 → 编辑 → 保存 → 用其他工具读取，编码保持 GBK 且内容正确。

### T13 execute

- 严格按 Step 0~5 顺序。
- 目录批逆序 → 文件批。
- 执行期不做前缀 remap。
- 失败即逆序回滚。

**通过标准**：
- 含目录改名时，文件与子目录全部到达终态。
- 交换名（A↔B）、大小写变化均成功。
- 人为制造第 N 项失败时，前 N-1 项被正确回滚。

### T14 rollback

- 日志位于 `Packages/User/MySideBar/rename_log.json`。
- 撤销逆序执行 + retarget。
- 只保留最近一次。

**通过标准**：执行一次批量改名后撤销，目录树与执行前完全一致。

## 4. 质量门禁（每个任务完成即执行）

1. ST4 中实际加载运行，无异常日志。
2. 检索确认无 `TODO`、无 `except: pass`、无硬编码用户字符串。
3. 新增代码不引入外部依赖。
4. `batch/` 与 `api.py` 不 import ST UI 模块。
5. 每任务完成后做两轮复盘：需求遗漏/边界，架构/权限/迭代成本；结论写入任务完成记录后，方可进入下一任务。
